----------------------------------------------------------------------
LESSONS LEARNED
----------------------------------------------------------------------

1. logging.basicConfig() is a no-op when uvicorn pre-configures the
   root logger before the FastAPI lifespan runs. Fix: add handlers
   directly to logging.getLogger() with a guard to avoid duplicates.

2. Windows venv health check: test for pyvenv.cfg, not python.exe.
   A broken venv can have python.exe without pyvenv.cfg (missing pip,
   packages not installed). build.bat now wipes and recreates if
   pyvenv.cfg is absent.

3. pythonw.exe fails silently. Any crash in a windowless Python process
   is invisible. Always redirect stdout/stderr to a log file when
   launching subprocesses via pythonw. tray.pyw now writes to
   log\tray.log and log\server_start.log.

4. pystray icon.stop() does not always exit the process on Windows —
   the Win32 message loop can leave threads dangling. Use os._exit(0)
   after icon.stop() to force a clean exit.

5. Tray Start/Stop only control processes the tray itself launched.
   If the server was started externally (scheduled task, run.bat), the
   tray's _server_proc is None. Fix: Stop uses netstat + taskkill to
   find and kill any process on port 8765; Start checks _is_up() first
   to avoid double-starting.

6. New Windows tray icons land in the hidden overflow area by default
   (the ^ arrow in the taskbar). Users must manually drag them to the
   visible area. Not a bug — just a Windows 11 UX thing to document.

7. The API session cookie must be shared across all urllib requests.
   Use http.cookiejar.CookieJar + urllib.request.build_opener so the
   login cookie persists for all subsequent API calls from the tray.
